## Видение

Программа для обработки звука: что-то вроде Audacity / DAW.
Ядро доступно из других программ. UI — опциональный слой поверх ядра.

## Архитектура: ядро и UI

Workspace из двух крейтов:

- **`la-core`** — ядро обработки звука. Без UI-зависимостей (нет Iced, нет Bevy).
  Публичное API для использования из других программ.
- **`la-ui`** — UI на Iced. Тонкий слой: вызывает `la-core`.

Правило: вся логика — в `la-core`. `la-ui` только рисует и пробрасывает ввод.

## Журнал решений

- **Ядро отделено от UI.** `la-core` без Iced, `la-ui` — тонкий слой.
  Обоснование: ядро нужно использовать из других программ.

- **Аудио-бэкенд: `cpal` + `symphonia`.**
  `cpal` — ввод/вывод звука (низкий уровень, кроссплатформенно).
  `symphonia` — декодирование файлов (WAV/MP3/FLAC/OGG и др.).
  Обоснование: полный контроль над аудиопотоком, что критично для DAW;
  оба — стандарт в Rust-аудио-экосистеме.

- **UI: `iced` + `iced_audio`.**
  Обоснование: reactive rendering (перерисовка только при изменении состояния,
  не как egui, но и не требует событий мыши как GPUI);
  `iced_audio` даёт готовые аудио-виджеты (фейдеры, ручки, XY-пады, dB/Hz-маппинги).

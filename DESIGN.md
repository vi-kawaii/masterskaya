## Видение

Программа для рисования. Ядро доступно из других программ, UI —
опциональный слой поверх ядра.

Одно предложение, дальше уточним: пользователь рисует кистями/фигурами
на холсте, работает со слоями, сохраняет и экспортирует результат.

## Архитектура: ядро и UI

Workspace из двух крейтов:

- **`pen-core`** — ядро редактора рисования. Headless, без UI-зависимостей.
  Публичное API для использования из других программ.
- **`pen-ui`** — UI на Bevy. Тонкий слой: вызывает `pen-core`.

Правило: вся логика — в `pen-core`. `pen-ui` только рисует и пробрасывает ввод.

## Журнал решений

- **Ядро отделено от UI.** `pen-core` без Bevy и любых UI-фреймворков.
  Обоснование: ядро нужно использовать из других программ и тестировать
  headless.

- **UI на Bevy.** Как в остальных проектах мастерской (`v`, `animeow`,
  `cinema`, `la`, `tv`). Обоснование: единый стек, общий каркас
  `libs/app-shell`.

# DESIGN.md — tv

Живой роадмап. Открыл — видишь, что сделано, что дальше.

## Видение

Программа в духе OBS, но **без интерфейса** — headless-ядро на чистом Rust.
Никаких тяжелых бинарных зависимостей от C++ комбайнов (`libobs`), только нативные крейты.
UI может появиться позже как отдельный слой.

## Архитектура: ядро и UI

Workspace из двух крейтов:

- **`tv-core`** — headless-ядро: захват экрана/аудио, кодирование и сетевой транспорт.
- **`tv-ui`** — UI на Bevy (пока пустой). Опциональный слой.

Основной сценарий — работа `tv-core` как автономного демона/сервиса.

## Технологический стек (Rust-native)

- **Захват видео:** `scrap` (или системные API под разные ОС)
- **Захват аудио:** `cpal`
- **Кодирование:** `ffmpeg-next` (или прямые обертки над NVENC / QuickSync)
- **Транспорт/Стриминг:** `rtmp` / `tokio-rtmp` или `srt-rs` для отправки на YouTube / Twitch

## Установка и запуск

Поскольку проект собирается полностью на чистых Rust-крейтах, никаких сторонних установщиков утилит (`cargo-obs-build`) не требуется. Стандартный toolchain Cargo:

```bash
# 1. Сборка ядра в режиме разработки
cargo build -p tv-core

# 2. Запуск headless-ядра
cargo run -p tv-core

# 3. Сборка релизной версии
cargo build --release -p tv-core
```

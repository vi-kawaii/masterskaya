## Видение

Программа для рисования с поддержкой **растровой и векторной графики одновременно**.
Ядро доступно из других программ, UI — опциональный слой поверх ядра.

Пользователь рисует кистями/фигурами на холсте, работает со слоями,
сохраняет и экспортирует результат.

## Архитектура: ядро и UI

Workspace из двух крейтов:

- **`pen-core`** — ядро редактора рисования. Headless, без UI-зависимостей.
  Публичное API для использования из других программ.
- **`pen-ui`** — UI на **iced**. Тонкий слой: вызывает `pen-core`.

Правило: вся логика — в `pen-core`. `pen-ui` только рисует и пробрасывает ввод.

## Стек технологий

### Почему не Bevy

Bevy — это игровой движок с ECS, scheduler, asset pipeline, аудио и сетью.
Для GUI-приложения с одним холстом это **избыточная сложность**.
Нам нужен чистый GUI-фреймворк и полный контроль над рендерингом холста.

### UI: iced

- Зрелый GUI-фреймворк с Elm-архитектурой (state, message, update, view).
- Собственный рендерер на wgpu.
- Виджет `shader::Program` даёт **прямой доступ к `wgpu::Device` и `wgpu::Queue`**.
- Нет оверхеда игрового движка.

### Рендеринг холста: wgpu + lyon

- **`wgpu`** — кросс-платформенный графический API (Vulkan, Metal, D3D12, OpenGL).
- **`lyon`** — тесселяция векторных путей (кривые Безье → треугольники) для GPU.
- **Растр**: загрузка пикселей в `wgpu::Texture`.
- **Вектор**: тесселяция через `lyon` → загрузка вершин в GPU-буфер → рендеринг.

Виджет `shader::Program` в iced позволяет реализовать кастомный `Primitive`,
который получает доступ к wgpu и управляет рендерингом холста.

### Сериализация

- **`serde`** + **`ron`** (или JSON) для сохранения/загрузки документов в `pen-core`.

## Журнал решений

- **Ядро отделено от UI.** `pen-core` без iced и любых UI-фреймворков.
  Обоснование: ядро нужно использовать из других программ и тестировать
  headless.

- **UI на iced, не на Bevy.** Bevy — игровой движок с оверхедом для GUI.
  iced даёт виджет `shader` для полного контроля над рендерингом холста
  через wgpu, без лишних абстракций.

- **Гибридный растр + вектор.** `wgpu` позволяет сосуществовать текстурам
  (растр) и тесселированным мешам (вектор) в одном конвейере.

- **`lyon` для векторов.** Тесселяция путей в треугольники для GPU.
  Не привязан к конкретному рендереру, отдаёт vertex/index buffers.

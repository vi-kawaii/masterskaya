## Видение

Программа в духе OBS с модульной архитектурой: эффективное headless-ядро для захвата и микширования видео на базе `libobs` и современный, быстрый графический интерфейс на **GPUI**.

## Архитектура: ядро и UI

Workspace из двух крейтов:

- **`tv-core`** — headless-ядро: инициализация сессии `libobs`, динамическая загрузка источников из конфигурации (`config.ron`), компоновка сцены и трансляция кадров рендеринга через потокобезопасные каналы.
- **`tv-ui`** — легковесный UI на **GPUI** с использованием **`gpui-kit`**: нативное окно предпросмотра, элементы управления в реальном времени и отображение живого видеопотока.

Основной запуск настроен на точку входа `tv-ui`, которая поднимает графическую оболочку и управляет фоновым потоком ядра.

## Технологический стек

- **Ядро захвата и композитинга:** `libobs-wrapper` / `libobs`
- **Конфигурация:** `ron` (Rusty Object Notation) + `serde`
- **Графический интерфейс:** `gpui` + `gpui-kit`
- **Ассеты:** `rust-embed` — встраивание графических ресурсов (`assets/`) в бинарник на этапе компиляции через собственный `AssetSource`.
- **Межпоточный транспорт:** `std::sync::mpsc` — передача событий `CoreEvent` из потока ядра в UI.

## Протокол обмена: `CoreEvent`

Ядро (`tv-core`) отправляет в UI (`tv-ui`) события через канал `mpsc::Sender<CoreEvent>`:

```rust
pub enum CoreEvent {
    /// Конфиг загружен — UI получает пути к ассетам и параметры сцены
    ConfigLoaded(Config),
    /// Очередной кадр видеопотока (RGBA, 1280x720)
    Frame(Vec<u8>),
}
```

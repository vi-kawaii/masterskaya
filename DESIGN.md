## Видение

Программа в духе OBS, но **без интерфейса** — headless-ядро.
UI может появиться позже как отдельный слой.

## Архитектура: ядро и UI

Workspace из двух крейтов:

- **`tv-core`** — ядро: захват, микширование, вывод. Headless.
- **`tv-ui`** — UI на Bevy (пока пустой). Опциональный слой.

Основной сценарий — работа `tv-core` без UI. `tv-ui` добавляется,
когда понадобится.

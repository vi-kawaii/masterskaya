## Журнал решений

- **Не web-based, не Tauri.** Зафиксировано на старте.
- **UI — GPUI.** Нативный, Rust, GPU-рендеринг, не web.
  Берём через фасад `gpui-kit`, который фиксирует совместимые
  версии GPUI и даёт готовую точку входа + компоненты.
  Осознанный риск: GPUI pre-1.0, API меняется между версиями.
- **DnD в ОС — отдельный слой, не через фреймворк.**
  DnD и буфер обмена — системные механизмы. Фреймворк отвечает
  только за старт drag внутри окна; передачу наружу делаем через
  `drag-rs` или прямые системные вызовы (OLE на Windows,
  NSPasteboard на macOS, GTK/Wayland на Linux).
  Известное ограничение: Linux + winit — `drag-rs` не работает
  без GTK-виджета. На Windows/macOS проблем нет.
- **Хранилище — SQLite с самого начала.** Поиск по тегам, имени,
  позже — визуальное сходство. Файловая система как источник
  картинок, SQLite как индекс метаданных. Начинать на чистой ФС
  и переезжать позже — дороже.

## Заметки по GPUI

- `gpui_kit::init(cx)` вызывается **до** `open_window`.
- `Root` (из `gpui_kit::component`) должен быть **первым уровнем**
  в окне, иначе компоненты ведут себя непредсказуемо.
- `open_window` на старте — **без `cx.spawn`**. `spawn` возвращает
  `Task`, который при игнорировании отменяется мгновенно, и окно
  не успевает создаться.
- Зависимости: `gpui-kit`, `anyhow`. Первая сборка долгая
  (компилируется `taffy`, `resvg`, `image`, `windows`-крейты).

## Архитектурные решения (Хранение и Поиск)

- **Локальное хранилище — `redb` (чистый Rust).**
  Отказываемся от тяжелых SQL-баз и громоздких схем.
  Масштаб проекта — локальная база на ~10 000 стикеров, которая полностью
  укладывается в кэш оперативной памяти. Быстрый и надежный key-value /
  структурированный движок без внешних C-зависимостей.
- **Поиск — единая строка в стиле Discord / Google.**
  Никаких лишних кнопок, выпадающих списков и фильтров. Один инпут:
  - Обычные слова → поиск по имени / пути (`кот`)
  - `#тег` → поиск по тегам стиля, персонажей или эмоций (`#аниме`)
  - `-исключение` → убрать лишнее (`-гиф`)
  - `"точная фраза"` → строгая последовательность в кавычках
